酒店早餐

Marché couvert Beauvau + Marché d'Aligre

巴黎最有生活感的市場段落之一，熟食、蔬果、芝士與街坊節奏全都濃縮在同一個早上。

Scene Note
這裡比大型景點更像真正的巴黎日常，適合慢慢逛、邊走邊看，也適合買少量零食當作接下來散步的補給。

Canal Saint-Martin 運河散步 + Rue Beaurepaire 探索
